# Jokenpo Yu-Gi-Oh

Este é um jogo de Jokenpo (Pedra, Papel e Tesoura) de um único jogador, usando cartas do Yu-Gi-Oh. O jogo é desenvolvido com HTML5, CSS3 e JavaScript. A estrutura de arquivos é organizadada da seguinte forma:

## Estrutura de Arquivos

```
src/
│
├── assets/
│   ├── audios/
│   ├── cursor/
│   ├── favicon/
│   ├── icons/
│   ├── rpg/
│   └── video/
│
├── scripts/
│   └── engine.js
│
└── styles/
    ├── buttons.css
    ├── containers_and_frames.css
    ├── main.css
    └── reset.css
```

## Cartas do Jogo

No jogo, você pode escolher entre 3 cartas:
- **Blue Eyes White Dragon** (Papel)
- **Dark Magician** (Rock)
- **Exodia the Forbidden One** (Tesoura)

## Regras

- O jogo é jogado contra o computador.
- Não há habilidades especiais, cartas mágicas ou cartas de armadilha.
- O objetivo é ganhar do computador em uma partida de Jokenpo.

Divirta-se jogando!
